# AI Agent HQ — Android PWA

## 실행
- 이 폴더의 파일을 HTTPS 정적 호스팅(Vercel 등)에 배포합니다.
- Android Chrome에서 배포 주소를 엽니다.
- Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.

## 현재 기능
- CEO + 25개 전문 에이전트 역할 목록
- 4개 본부별 보기와 검색
- 에이전트 상세 역할
- 업무 요청 등록 및 브라우저 로컬 저장
- PWA manifest 및 오프라인 캐시

## 중요 제한
이 버전은 프런트엔드 시제품입니다. 실제 AI 모델 호출, 계정 로그인, 서버 DB 저장, 관리자 권한, 카카오톡 연동은 포함하지 않습니다. 등록한 업무는 현재 브라우저의 localStorage에 저장됩니다.
